# Fixture provenance

These archives contain three original synthetic RGB PNG images generated by
`../../../experiments/cbr-wasm/generate-fixtures.cjs`. The images and generator use this repository's
MIT OR Apache-2.0 license. There is no downloaded comic artwork.

The generator uses `@bitplane/rars` 0.9.4 with `level: 3`, formats `rar40` and
`rar50`, and solid compression both off and on. Archive order is page10.png,
page2.png, page1.png, to test natural sorting independently of archive order.
Every image is 128 by 128 pixels and 49,348 bytes. PNG IDAT uses zlib level 0 so
the RAR decoder must decompress image content rather than only list headers.
The generator fixes entry timestamps to 2024-01-01 UTC.

`node experiments/cbr-wasm/verify-fixtures.cjs` verifies all three extracted images from each
archive against the PNG files using `node-unrar-js` 2.0.2, an independent
UnRAR implementation. This avoids validating rars against itself alone.
The four archive sizes are 5,999, 4,040, 4,815, and 127,742 bytes.
SHA-256 hashes are recorded in `experiments/cbr-wasm/evidence/artifacts.json`.

From `experiments/cbr-wasm`, `node generate-fixtures.cjs --large` generates
512 by 768 pixel fixtures under ignored `artifacts/large/`. Those use a fixed
xorshift sequence, contain 1,180,659-byte PNGs, and have archive sizes around
3.54 MB. They exercise incompressible image content and resource limits.
`node verify-fixtures.cjs --large` checks them with UnRAR as well.

No proprietary `rar` executable is needed. rars now writes these formats;
`bsdtar` and `7z` were not used as RAR writers.
